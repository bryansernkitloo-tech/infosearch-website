Email Signature Generator

Create your email signature

Type your name (and title if different), then copy your personalised signature straight into Outlook. Two versions are generated: one with the confidentiality disclaimer for new emails, one without for replies.

Your details

Defaults to “Chartered Secretary” — change only if yours differs.

How to install (Outlook)

  1. Click Copy — New emails below.
  2. Outlook: File → Options → Mail → Signatures.
  3. New, name it, paste into the box.
  4. Repeat with Copy — Replies as a second signature.
  5. Set New messages → the disclaimer one; Replies/forwards → the reply one.
